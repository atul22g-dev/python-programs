⚙️ Installation

Up and running in one command

The whole repo shares a single environment — uv finds the root pyproject.toml from any subfolder, so there's no per-project setup

1

Install uv

uv is the modern Python package & project manager. Install it with pip:

pip install uv
2

Install everything

uv sync creates a virtualenv and installs every dependency for every project in one go:

uv sync
3

Run any project

Missing dependencies auto-install on first run — this one command is a complete setup + run:

uv run run-project "Snake Game"
💡

Tips

  • Run uv run run-project with no arguments for an interactive project picker, or uv run run-project --list to see every project.
  • Prefer classic per-project runs? cd "Games/Snake Game" && uv run python main.py — uv auto-installs deps the first time.
  • sketchpy (Iron Man RDJ) is intentionally not in pyproject.toml — it wrongly lists the stdlib turtle module as a PyPI dependency. The runner installs it with pip install --no-deps sketchpy.
1

Install virtualenv

Classic approach, if you prefer pip over uv:

pip install virtualenv
2

Create the environment

One shared virtualenv for the whole repo:

virtualenv .venv
3

Activate it

Windows (PowerShell)

.\\.venv\\Scripts\\Activate.ps1

macOS / Linux

source .venv/bin/activate
4

Install dependencies

Install what the projects you want need — or freeze an existing environment with pip freeze > requirements.txt and install from that:

pip install pygame pandas opencv-python
5

Run a project

From inside the project folder:

cd "Games/Snake Game" && python main.py
💡

Notes

  • On Windows, PowerShell may need Set-ExecutionPolicy RemoteSigned (answer y) before activating a virtualenv.
  • Deactivate any time with deactivate.
  • Prefer the Quick Start tab — uv sync does steps 2–4 automatically.
1

Install PyInstaller

Packages Python programs into standalone executables:

pip install pyinstaller
2

Build the executable

Run it from the project folder, pointing at the main file:

pyinstaller your_program.py
3

Or build a single file

Everything bundled into one .exe:

pyinstaller --onefile your_program.py
💡

Notes

  • The executable lands in the dist/ folder.
  • Add --windowed for GUI apps so no console window opens, and --icon app.ico for a custom icon.
