# Itachi Sketch

A sketch of Itachi Uchiha drawn with turtle, using OpenCV edge detection:
the photo is converted to an outline, then a turtle replays the edges
line by line.

![Alt text](itachi.jpg?raw=true "Itachi Uchiha")

## Requirements

```bash
pip install opencv-python
pip install numpy
pip install matplotlib
```

## Usage

Run it from this folder (or use `uv run run-project "Itachi Sketch"`):

```bash
python main.py
```
